# Pure HTML + CSS + JavaScript version

This folder contains the cinematic page converted to a standalone HTML/CSS/JavaScript project.

## Files
- index.html — page markup
- cinematic.css — styling
- cinematic.js — scroll/video/menu behavior
- mp4box.all.min.js — JavaScript MP4 parser used by the original page
- frames/ — original frame fallback assets

## Run
Use VS Code Live Server (recommended) or any static web server and open index.html.

No React, TypeScript, Tailwind, Vite, npm, or other application framework is included.

The original cinematic HTML/CSS/JS and frame assets are preserved; only the React/TanStack wrapper has been removed.
